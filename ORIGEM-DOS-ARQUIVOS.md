# Origem dos arquivos

Os fontes e a identidade visual foram conferidos com a pasta `SystemBR-Cloud-Desktop` da Área de Trabalho em 03/11/2026.

Os arquivos de código presentes nas duas versões são idênticos, exceto pelas adaptações necessárias em `.craft.ini`, `.tag`, `CMakeLists.txt`, `OWNCLOUD.cmake`, `src/gui/CMakeLists.txt` e `src/gui/MacOSXBundleInfo.plist`. O ícone `systembr-cloud.icns` é específico do macOS.

As imagens oficiais em `branding-assets` foram copiadas diretamente do projeto Windows, mantendo o fundo transparente original. O cliente mantém Cloud System BR e o servidor sugerido e editável https://cloud.systembr.com.br/.

Instaladores MSI, SDK do Windows, chaves de assinatura e arquivos de entrega não são usados como fontes de compilação macOS. As licenças e os créditos originais permanecem preservados.
